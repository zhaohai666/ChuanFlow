# ChuanFlow 对标 Pipesim / OLGA / Fluent 能力差异清单

> 本文档记录 ChuanFlow 相对 **Pipesim / OLGA / Fluent** 三款商业软件的现存能力差异，作为"继续排查还有哪些能力没有实现"工作线的单一可信来源。
>
> - 每完成一个增量，本文档同步更新：状态列从 `OPEN` → `IN_PROGRESS` → `CLOSED`，并在末尾的"实施日志"里追加一行实测结果。
> - 与 README 的关系：README 声明"已落地"的能力**不**列在本文档里；本文档只列**尚未落地**或**落地不完整**的能力。
> - 与 `docs/architecture.md` §5.x 的关系：架构文档里的"边界①/②/…"是已命名但未关闭的格子；本文档把它们按**实施成本**重新归组，不再按增量号排列。
> - 与根目录 memory 文件 `project-chuanflow-benchmark-gaps.md` 的关系：memory 文件记录"为什么某条路径走不通"等不可提交的中间知识；本文档只记录"还差什么"与"做到哪一步"。

## 0. 阅读方式

每个差异项包含以下字段：

| 字段 | 含义 |
|------|------|
| **ID** | 唯一编号；前缀字母表示所属类别（A / B / C / D） |
| **能力** | 商业软件里的名字 |
| **参考工具** | 在 Pipesim / OLGA / Fluent 中的对应功能 |
| **当前状态** | `OPEN` / `IN_PROGRESS` / `CLOSED` / `BLOCKED` |
| **阻塞项** | 状态为 `BLOCKED` 时给出阻塞原因 |
| **内核改动** | 需要修改的内核文件 / 函数（如已知） |
| **成本估计** | 以"增量"为单位（一个 §5.x 小节 = 1 增量） |
| **落点** | 完成后写入的 architecture.md 章节号 |

状态机：

```
        ┌──── OPEN ────┐
        │              │
        ▼              │
   IN_PROGRESS ───► CLOSED
        │
        ▼
     BLOCKED  ──（阻塞解除）──► IN_PROGRESS
```

> **落点编号说明（2026-11-11 审计）**：带「（预估）」的 §5.x 落点只是**占位编号**，实际按增量关闭顺序分配，不预留。架构文档当前已用到 **§5.89**（§5.63 = C1/A4，§5.64 = B6，§5.65 = C2，§5.66 = C4，§5.67 = B5，§5.68 = D5，§5.69 = A7，§5.70 = A3，§5.71 = A9，§5.72 = A10，§5.73 = A6，§5.74 = A2，§5.75 = A5 增量 1，§5.76 = A5 增量 2，§5.77 = A5 增量 3，§5.78 = A8 增量 1，§5.79 = A8 增量 2，§5.80 = C3 增量 1，§5.81 = D1 增量 1，§5.82 = D3 增量 1，§5.83 = A1，§5.84 = D3 增量 2，§5.85 = D4 增量 1，§5.86 = D1 增量 2，§5.87 = C3 增量 2，§5.88 = D4 增量 2，§5.89 = D1 增量 3）；因此 A2 原写 §5.63 已被占用，C3 原写 §5.66 与 A6 的 §5.67 不一致。这几条在本轮审计里改为「待分配 / 顺延」，其余预估编号维持不动，等该项真正启动时再定。

### A1. 屈服 + 湍流摩擦闭合（Darby–Metzner / Wilson–Thomas 类）

- **参考工具**：Pipesim / OLGA 非牛顿湍流管段默认行为
- **当前状态**：`CLOSED`（2026-11-13，§5.83）
- **阻塞项**：无（2006 Eq (15)/(16) 与 2007 Eq [3]/[4] 已确认逐字相同，β 的解方程形式 settled；两份已提取文本 `/tmp/wilson_thomas.pdf`、`/tmp/wilson_rough.pdf.txt` 留档）
- **内核改动**：`src/1d/src/network.cpp` 新增 `binghamTransitionRe(He)`（locus 报告与摩擦开关共享同一函数，两者不漂移）+ `yieldedTurbulentFriction(Re_B, He)`（Eq 15/16 在 β>1 上括号二分，回代 `f = 8Heβ/Re_B²`，`log1p` 保大 β 精度）；`pipeFrictionPa` 与 `pipeFrictionReport` 两处开关——光滑（`roughness ≤ 0`）Bingham（`flowIndex == 0`）且 **Re_B 严格 > Re_B,t** 才按湍流定价，否则层流 Buckingham；`yieldedTransitionOf` band 重构 + `dpAtTransition` 显式钉层流（间隙地板）。`pipeFrictionPa` 稳态/瞬态共享，一处覆盖两侧。**无新声明键**（读既有 yieldStress/flowIndex/roughness）。
- **成本估计**：1 增量（设计已 settled，只差转录核对）；实测 ~1
- **落点**：architecture.md **§5.83**（原预估 §5.73 已被 A6 占用）
- **已测量**：扩展 `steadyYieldTransition`（**复用 `verify.steadyYieldTransition`，不新增 test，CTest 仍 137**），**67 判据 0 失败**。locus 以上 **7 管**按 Wilson–Thomas 湍流定价：printed f = 此处独立重推 Eq 15/16（纯 `math.log` 路径，worst 2.11e-12）、湍流精确根（worst 6.39e-13）、f 复现压降 `(f L/d)ρv²/2`（worst 7.75e-12）；最深管（Edge1e5Under/Edge1e5Over/BigHe06Run，Re_B 数万~数十万）**不再**答 `64/(Re_B g)`（层流括号偏 >10%，正是本增量要停止复现的数）。locus 以下 **8 管**仍层流 Buckingham 根（worst 3.2e-12）+ `f·Re_B·g = 64`（worst 1.86e-12）。**滞回间隙**：硬开关在 locus 不连续——低 He 管 `dp_t,turb > dp_t,lam`（Small05 间隙 403.08~625.84 Pa，探针从 500 移到 700 Pa 良态区），极高 He band-2 可重叠（符号在 He=1e5 两侧翻转）；**不发明未经确认混合律填缝**，case 探针放良态区。
- **关闭时留下的边界**：① **仅光滑壁**（粗糙壁湍流屈服闭合 2007 Eq [7]/[9] 留待后续增量）；② HB 无塑性黏度 μ_B，故 He/Re_B 都不是关于它的陈述，保持层流；③ band 0→1（2100→1568.29，−25.3%）/ band 1→2（8000→7905.69，−1.17%）join 是**记录的台阶**（2006 Eq (17) 桥接常数无法从源排版转录）；④ 湍流档无实验真值可验，判据锁独立重推 Eq 15/16 与内核逐位吻合，不是拟合实验。
